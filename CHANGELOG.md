
# Changelog

All notable changes to the Network Security — SSH and
Man-in-the-Middle Analysis project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Conceptual system architecture diagram.
- Structured technical documentation for network security analysis.
- Documentation of ARP security and network trust relationships.
- Documentation of SSH communication and endpoint authentication.
- Documentation of Linux networking and packet analysis.
- Experimental environment specifications.
- Functional validation methodology.
- Defensive security considerations.
- Responsible use guidelines.
- Technical references and academic documentation links.
- Development roadmap.
- Documentation of project limitations and verification requirements.
- Third-party licensing and attribution considerations.

### Changed

- Restructured the README to improve technical clarity and readability.
- Corrected the repository description and technology classification.
- Reorganized documentation around protocol analysis, network trust,
  and defensive security engineering.
- Clarified the distinction between experimental security analysis
  and standalone software development.
- Standardized academic attribution and author information.
- Clarified the scope of repository licensing.

## [1.0.0] - Initial public version

### Added

- Experimental Man-in-the-Middle security investigation.
- ARP protocol and network trust analysis.
- SSH communication and authentication analysis.
- Wireshark-assisted network packet inspection.
- Linux networking and virtual network investigation.
- Experimental analysis using established network security tools.
- Original academic project specification.
- Academic technical report.
- Project documentation and contribution guidelines.

### Known Limitations

- Reproducibility of the original laboratory environment
  requires further verification.
- Compatibility with contemporary Linux distributions
  and security analysis tools remains unverified.
- Independent validation of experimental observations
  is not yet established.
- Systematic evaluation of defensive mechanisms remains pending.
- Automated validation procedures are not yet established.
- The repository does not contain a standalone
  network security application.
- Third-party licensing and redistribution rights require review.
- The project is not intended for production deployment.
